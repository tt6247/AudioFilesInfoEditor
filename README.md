# 音档工坊

中文 Windows 桌面音频标签编辑工具。所有操作在本机完成，无需上传音档。

## 启动

- **直接运行**：在 [Releases 下载页面](https://github.com/tt6247/AudioFilesInfoEditor/releases/latest) 下载 `AudioFilesInfoEditor-v1.1.exe`（含中文输入修复与空标题补填），双击运行，无需安装 Python。本地打包结果位于 `dist/`。
- **运行源码**：安装 Python 3.10 或更新版本，双击 `start.bat`。首次启动会在项目内安装 Mutagen；也可运行 `python -m pip install --target .vendor -r requirements.txt`，然后 `python app.py`。

## 使用

1. 添加多个音档，或添加整个文件夹（自动包含子文件夹，跳过备份目录）。
2. 用 Ctrl / Shift 多选音档；搜索框可按文件名或标签搜索，格式菜单可筛选。全选只选择当前筛选结果。
3. 右侧勾选需要修改的字段并输入内容。**未勾选的字段保持原值；勾选但留空会清除该字段。** 默认启用空标题自动补填，详情见下文。输入时会自动勾选。切换所选音档时，已经勾选的待修改内容会保留；点击“重置待修改内容”重新载入所选文件的公共值。
4. 点击“预览并保存修改”，检查逐首修改记录，再确认保存。
5. 当前会话可用“撤销上次保存”恢复最近一次成功保存的批次。失败的文件会单独列出，可查看原因并刷新后重试。

快捷键：`Ctrl+O` 添加文件；`Ctrl+S` 预览保存；列表中 `Ctrl+A` 全选，`Delete` 移出列表。移出列表不会删除文件。

中文输入：点击输入框后，可使用系统中文输入法。如无法切换或不显示候选字，点击右侧“中文输入”按钮，会为当前输入框连接已安装的中文输入法，再继续输入。程序只切换自身窗口的输入状态，不修改系统语言配置。如果窗口由受限执行环境启动，可能无法访问系统输入法；请关闭该窗口，在文件管理器中双击启动 EXE，无需以管理员身份运行。

空标题自动补填：默认开启“空标题自动用文件名补填”。标题缺失、空字符串或只有空白时，使用该音档自身的文件名，去掉最后的扩展名。例如 `晴天.mp3` 补填为 `晴天`，`演唱会.live.flac` 补填为 `演唱会.live`。已有标题保持不变。列表中以“待补填”标记，选择单首时可在标题框看到建议内容；仅添加、刷新不会改写原文件。选中音档后，即使未勾选其他字段，也可直接预览并保存补填内容。批量操作会为每首歌分别使用其自身文件名。手动勾选标题后，优先使用手动输入（包括主动清空）；也可关闭该自动补填选项。

## 功能

- 编辑标题、歌手、专辑、专辑歌手、曲风、发行日期、音轨编号、碟片编号、作曲者、备注。
- 显示格式、编码、码率、时长、采样率、声道、位深（如可读取）、大小与文件路径。
- 支持 MP3、FLAC、M4A/M4B/MP4（AAC / ALAC）、OGG Vorbis / FLAC、Opus、WAV、AIFF、WMA。
- 缺少码率信息时，显示带 `≈` 的估算总文件码率（包含容器与标签开销）。Opus 显示 48 kHz 解码采样率。未知参数显示为 `—`。
- 只编辑标签，不转码。封面及其他未选中的标签由标签库保留；ID3 标签使用 Mutagen 的 ID3v2.4 保存机制。不同播放器对 WAV / AIFF 的 ID3 标签支持可能不同。
- 多值标签以 `; ` 展示；本版本将输入框的新内容作为单一文本写入。选择修改备注时，会替换该文件已有的备注。

## 备份与恢复

保存时先将副本写入、重新读取并验证，再备份原文件，最后替换原文件。某首失败不影响其余文件。停止按钮会在当前文件处理完成后停止。

备份位于每个音档原目录下的 `.audio-tag-backups/批次编号/`，保留完整原始文件，并附带记录原路径的 JSON 文件。备份不会自动删除；需要足够空间容纳工作副本和原始备份。

关闭程序后，如需恢复，可根据 JSON 中的 `original` 路径，将对应的备份音档复制回原路径。自动撤销会检查文件大小和修改时间；如果保存后文件再次被改动，将拒绝覆盖，保留手动恢复的选择。
